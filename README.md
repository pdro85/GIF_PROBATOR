# GIF Probator

Herramienta gratuita para uso personal, educativo y no comercial. Sirve para probar animaciones por frames y exportarlas como GIF desde el navegador.

![GIF Probator](Captura%20de%20pantalla%202026-05-21%20210456.png)

## Uso

Abre `index.html` en tu navegador. No necesita servidor, instalacion ni internet.

Funciones principales:

- Cargar varias imagenes como frames.
- Reordenar, duplicar y eliminar frames.
- Crear frames en blanco y dibujar sobre cada frame.
- Ajustar FPS global o duracion individual por frame.
- Previsualizar la animacion con fondo de ajedrez, cuadricula y modo de frame anterior.
- Cambiar el tamano del lienzo y el encaje de imagen.
- Exportar un GIF animado localmente.
